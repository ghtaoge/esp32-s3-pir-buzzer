# 感应小哨兵微信小程序

这是 HC-SR505（三脚 PIR）专用的原生微信小程序，可连接实际开发板，不是浏览器 Web Bluetooth 页面。需要带硬件 profile 的 1.0.2 或更新固件，连接时会核对 HC-SR505、OUT GPIO13、蜂鸣器 GPIO7；旧版或不同接线的固件会明确拒绝连接，避免显示错误接线。

1. 用微信开发者工具导入本目录。公开的 `project.config.json` 仅使用 `touristappid`。
2. 将 `project.private.config.json.example` 复制为 `project.private.config.json`，在该私有文件填入你自己的微信小程序 AppID。该文件已被本目录 `.gitignore` 排除。不要将真实 AppID、上传密钥或其他项目的配置写入共享文件。
3. 真机 BLE 预览需使用有权限的真实小程序 AppID。在小程序后台用户隐私保护指引中声明蓝牙用途；按微信和系统提示授权。游客项目、开发工具模拟器不能替代真机蓝牙验证。
4. 开发板烧录本仓库固件后，搜索名称为 `S3-Sentinel-xxxxxx` 的设备。首次连接会读取参数、校准本次启动的时间，并增量同步记录。

三个标签分别用于设备控制、设备参数、记录同步。传感器固定为 HC-SR505，不提供其他传感器选项。保存参数仅在收到固件成功 ACK 后显示成功。请求超时会关闭连接，写操作不会自动重放。重新连接后先检查当前参数再决定是否重做。旧设置迁移或专用配置保存失败会在页面提示，保存失败时可重新保存。

声音预设支持单音、双响、叮咚、警报，默认单音。无源模块可生成音高变化，有源模块仅能改变固定音高的开关节奏，警报预设在有源模块上与单音相同。“试听设备声音”发送真实 `test` 命令，按已保存预设和时长执行，不播放手机模拟声音；尚未保存的声音修改不会用于试听。

HC-SR505 接线固定为 VCC→5V、GND→GND、OUT→GPIO13。蜂鸣器 S/IN→GPIO7，并与开发板共地，蜂鸣器供电按其规格连接。三脚蜂鸣器不一定有源，请按实物资料选模式；有源模块还需确认控制输入兼容 3.3V 及高/低触发极性。

HC-SR505 的硬件灵敏度和输出保持时间不能通过小程序调节。确认时间、连续低电平释放时间、启动稳定时间均是程序等待时间。设备页的 OUT 高仅表示检测信号保持为高，不能证明人此刻仍在活动或静止在场；页面不显示测距、能量或静止存在指标。活动触发记录是一轮检测输出片段，不代表人数。

手机按稳定芯片 `deviceId` 分别缓存最多 1000 条，以序号去重；通知不推进历史同步游标，每页 ACK 后推进游标。页面每次只显示 25 条，可展开至最近 100 条。清除设备记录需要确认且只在固件 ACK 后清除本设备手机缓存。没有校时的旧记录显示启动编号与相对时间，不补造日期。

BLE 每块最多 20 字节，逐块等待原生写入确认并检查连接会话，块间默认额外间隔 5 毫秒。实际同步速率受手机、蓝牙连接参数和无线环境影响，不保证固定速度或完成时间。

切到后台会主动断开蓝牙，开发板继续本地运行；回来后需重新搜索连接，记录从确认游标继续同步。该版本没有云端、远程告警或后台常驻承诺。

在仓库根目录运行测试：

```powershell
node --test miniprogram/tests/*.test.js
```

本地测试覆盖协议/传输/缓存逻辑，不代表已通过 Android、iOS、HC-SR505 和具体蜂鸣器的真机联调。连接、调参、清除、断电重启等请按仓库验收步骤在实物上验证。
