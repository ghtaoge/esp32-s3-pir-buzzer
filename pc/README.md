# PC 控制台

运行环境：Node.js 22 或更新版本，以及桌面版 Chrome / Edge。无需安装 npm 依赖。

在仓库根目录运行：

```powershell
node pc/server.js
```

打开 <http://127.0.0.1:8787>。端口占用时使用 `node pc/server.js --port 8788`。
服务器仅监听 `127.0.0.1`，不向局域网或公网开放，不提供任意文件读取接口。

## 真实连接

- **USB**：开发板烧录本仓库固件，使用数据线连接；点击“连接 USB”，选择 ESP32-S3
  的 USB CDC 串口。串口速度为 115200。先关闭占用同一串口的串口监视器。
- **BLE**：点击“连接蓝牙”，选择 `S3-Sentinel-` 开头的设备。若系统或浏览器不支持
  Web Bluetooth，请使用 USB，或用微信小程序连接。蓝牙只用于设备附近操作。
- **演示模式**：不需要硬件。所有状态、性能数字和事件均明确标为模拟；页面不播放声音。
  HC-SR505 一次触发的 OUT 默认模拟保持约 8 秒，也可模拟持高 10 秒，检查持续高电平
  不会延长鸣叫或重复计次。实际模块保持时间会有差异，演示不模拟热源与上电漂移。

Web Serial / Web Bluetooth 需要安全上下文，本地 `127.0.0.1` 满足浏览器要求。
这里的连接动作直接使用浏览器设备接口，服务器不会转发设备数据。

## 功能与记录

- 设备控制：布防、静音、立即停止、限时手动测试、实时状态及设备性能遥测。
- 当前硬件固定为 **HC-SR505（三脚PIR）**：VCC → 5V、GND → GND、OUT → GPIO13；
  蜂鸣器控制端使用 GPIO7，电源按模块额定电压。PC 连接时核对固件返回的硬件标识与
  引脚，拒绝不匹配的旧固件，避免接线与实际采集引脚不同。
- 可调整软件确认、平静恢复、鸣叫后冷却、上电稳定时间与声音。HC-SR505 的硬件
  灵敏度和输出保持时间不能由软件修改；持续高电平期间的新动作不能分开识别，也不能
  把高电平当作静止人体存在检测。当前端不提供距离、能量或更换传感器选项。
- 参数收到设备确认后才视为生效。旧配置会迁移到当前硬件方案；若设备报告迁移结果
  未持久化，页面明确提示并禁用保存、布防和静音写入，读取／停止／试听仍可使用。
- 声音预设：支持单音、双响、叮咚、警报，默认单音。无源蜂鸣器可改变节奏和音高，
  有源模块只能改变通断节奏、音高固定。先保存，再点击“试听已保存声音”；试听使用
  设备已保存的预设，不使用尚未保存的表单草稿。演示模式依然只显示状态，不播放音频。
- 记录：断线期间由设备独立记录，重连后从已确认游标补同步，按设备标识隔离缓存。
  本机最多保留 1000 条、每页渲染 50 条。手机和 PC 同时设置时，PC 只提交相对已读取
  基线实际修改的字段；未编辑的参数不会被旧表单整体覆盖。
- 手动测试会发声，绕过布防／静音，但不计入感应触发次数。日志“已启动鸣叫”表示
  控制输出被启动，不证明蜂鸣器实物正常，也不表示一定完整响满设定时长。
- 未校时的日志显示启动编号及开机相对时间；已校时日志固定显示北京时间。
- 可导出当前缓存为 CSV；清空设备记录需要明确确认，不会把持久化序号归零。

页面关闭或 PC 断开不影响真实设备本地检测；本地网页不是离家远程监控服务。
浏览器缓存满或被禁用时，数据同步仍可在内存中运行，请及时导出重要记录。

## 检查

```powershell
node --test pc/tests/*.test.js
```

测试涵盖真实协议的演示设备、持续活动限时停止、串口／BLE 取消连接清理、BLE 分片、
日志去重与上限、同步游标与覆盖、设备隔离缓存、未校时时间、CSV 公式注入防护和
本地服务器路由／Host 边界。USB / BLE 的实际无线、电气与声学效果仍需实板联调。
